# Design documents

These documents record the architectural contracts that are difficult to infer
from any one source file. They describe the current implementation unless a
section is explicitly marked **Proposed**.

- [Runtime and modules](runtime-and-modules.md)
- [Frontend API and contributions](frontend-api-and-contributions.md)
- [Continuity memory](continuity-memory.md)
- [Permission broker](permission-broker.md)

Before changing one of these systems, read its design document and update it as
part of the same change. A significant proposed change should be reviewed before
implementation.
